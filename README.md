# EIQ Analysis

基于 EIQ（Entry-Item-Quantity）分析模型的 ABC 分类统计与可视化工具，支持对商品销售数据进行自动分类（A/B/C/D 类），并以交互式饼图展示各类别的销量占比。

> 参考书籍：《超简单用Python让Excel飞起来》，王秀文，机械工业出版社。
> 技术指导：昆明九控科技有限公司。

## 功能特性

- **Excel 数据导入**：自动识别文件夹中的 Excel 文件（.xlsx / .xls），转换为 CSV 进行高效处理
- **数据清洗**：自动清理销售量列中的非数值字符，确保数据准确性
- **灵活分类**：支持 1~3 段 ABC 分类，用户可自定义分类边界比例
  - 仅输入 **a**：分为 A 类（前 a%）和 B 类（剩余部分）
  - 输入 **a、b**：分为 A 类、B 类（a%~a%+b%）和 C 类（剩余部分），程序自动补全 C 类
  - 输入 **a、b、c**：分为 A/B/C/D 四类，总和必须恰好为 100
- **交互式可视化**：使用 matplotlib 绘制交互式饼图，支持翻页浏览各类别明细及总览
- **自适应 UI**：根据屏幕分辨率自动调整字体大小和图表布局

## 项目结构

```
EIQanalysis/1.0/
├── main.py              # 程序入口，流程编排
├── controller.py        # 主控逻辑：ABC 边界输入、分辨率检测、清理
├── draw.py              # 可视化模块：饼图绘制（分类明细 + 总览）
├── Excel2CSV.py         # Excel 转 CSV 转换器
├── filter.py            # CSV 数据清洗与过滤
├── statistician.py      # 数据统计：筛选、汇总、ABC 分类计算
├── path_input.py        # 文件路径输入与校验

```

## 安装与运行

### 1. 安装依赖

```bash
pip install pywin32 pandas matplotlib
```

### 2. 准备数据

准备一个包含商品销售数据的 Excel 文件，要求至少包含两列：
- **商品名列**：商品名称
- **销售量列**：对应的销售数量（数值类型）

### 3. 运行程序

```bash
python main.py
```

### 4. 使用流程

1. **选择文件夹**：在弹窗中输入包含 Excel 文件的文件夹路径
2. **指定列索引**：输入商品名和销售量所在列的大写字母索引（如 `A`、`B`）
3. **设置 ABC 边界**：
   - 程序会提示 A 类的建议下限和剩余部分的下限
   - 输入 `a`（必填）即可分为两类
   - 输入 `a` 和 `b` 分为三类（C 类自动补全）
   - 输入 `a`、`b` 和 `c` 分为四类（总和须为 100）
4. **查看图表**：
   - 首屏显示总览饼图（A/B/C/D 各类总销量占比）
   - 点击 **Next** 查看各类别明细饼图
   - 在明细图中点击 **Last** 返回总览
   - 点击 **Quit** 退出程序

## 核心模块说明

| 模块                | 职责                                     |
|-------------------|----------------------------------------|
| `main.py`         | 程序入口，串联数据读取、清洗、分类、可视化的完整流程             |
| `controller.py`   | 用户交互控制：ABC 边界输入校验、屏幕分辨率检测、运行结束清理       |
| `draw.py`         | 数据可视化：根据分类数量动态绘制饼图（支持 1/2/3 类切换）       |
| `Excel2CSV.py`    | 将文件夹中的 Excel 文件读取并转为 UTF-8-SIG 编码的 CSV |
| `filter.py`       | CSV 数据清洗：去除销售量列中的非数值字符                 |
| `statistician.py` | 数据统计引擎：数据筛选、销量汇总排序、按比例分配 ABC 分类        |
| `path_input.py`   | 文件路径输入校验：检查路径有效性及 Excel 文件存在性          |

## 注意事项

- 程序运行时会在工作目录下创建 `cache/` 文件夹存放临时 CSV 文件，运行结束后自动清理
- 销售量列中若包含非数值字符（如单位、空格），会被自动去除
- 商品名重复的商品会自动合并销量
- 程序依赖 Windows 平台 API（win32api），不支持直接在其他操作系统运行

## 已知问题

- **功能范围有限**：当前仅实现了销量分析功能，尚未支持金额分析、时间维度分析等其他 EIQ 分析场景
- **代码冗余**：部分模块存在重复逻辑，可进一步抽取公共函数减少冗余
- **规范性不足**：代码风格不统一，部分函数缺少类型注解和文档字符串（docstring）
- **鲁棒性不足**：异常处理不够完善，部分边界情况（如空文件、格式异常）可能导致程序崩溃
- **通用性不足**：硬编码了部分列索引和文件格式假设，对不同业务场景的适配能力有限
